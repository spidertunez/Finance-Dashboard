# Finance-Dashboard
Finance Dashboard designed to analyze project-based financial performance and profitability across departments and regions.
The dashboard provides actionable insights into ROI, Revenue, Profit, and Project Performance to support strategic decision-making.

🔹 Key KPIs:

ROI

Revenue per Project

Project Count

🔹 Insights & Analysis:

Profit by Region

Revenue Amount by Year & Month

Top Revenue-Generating Department

Profit for Each Project

🔹 Key Objectives:

Track financial performance at the project level

Identify the most profitable regions and departments

Monitor revenue trends over time

Support management with data-driven insights

🔹 Tools & Skills:

Power BI

DAX Measures

Financial Analysis

Data Visualization

Dashboard Design
